## 怎么复核

```bash
# 控件覆盖 + 各示例用到的控件数
python coverage.py token.txt

# 界面这一层由 e2e 守着
cd yudao-ui-admin-vue3
npx playwright test form-design-demos
```

e2e 会核对每个示例的演示数据齐全（每个配出来的列都有值），
以及那些「配了容易不生效」的能力真的生效了。
