## 十个示例在哪

【基础设施 → 开发示例 → 在线开发】。每个都带演示数据，打开就能看到效果；
配置本身可以在【基础设施 → 表单设计】里打开看。

| 示例 | 演示什么 |
|---|---|
| 控件总览示例 | 受支持的控件各一份，覆盖三种落库形态 |
| 列表标签页示例 | 按字段值把列表切成几个页签 |
| 列表行内编辑示例 | 点编辑不弹窗，就地改这一行并单独保存 |
| 列表左侧树示例 | 列表左边挂一棵树，点节点筛数据 |
| 客户档案示例 | 被别的表单关联的一方 |
| 跨表取数示例 | 选一条别的表单的记录，把它的字段带过来 |
| 控件数据接口示例 | 下拉选项来自数据接口 |
| 接口参数取字段示例 | 接口入参取自表单上另一个字段 |
| 复杂表头主子表示例 | 多级表头 + 明细列摊平 |
| 树形表格示例 | 自关联建树 |
| 销售订单示例 | 主子表 + 合计 + 公式 + 打印 + 变更记录 |

示例的构建脚本在 `ruoyi-vue-pro/script/form-demo/`，可以重复执行。

## 一条贯穿全模块的经验

这个模块里最常见的缺陷不是「报错」，而是**「配了、保存成功了、但根本没生效，且没有任何提示」**。
本手册每一章末尾都有一节「这些配法会静默失效」，配置前扫一眼比事后排查省事得多。

判断一个配置到底有没有生效，最可靠的办法只有一个：**在浏览器里真的走一遍**。
保存成功、发布成功、单元测试全绿，三者都不能替代它。
