# 07 · 运行时能力

配在「列表设计」这一步，作用在运行时的列表页与详情弹窗上。

## 自定义按钮

在内置按钮之外再加几个。每个按钮配：标识、文案、图标、位置（工具栏 / 行内 / 详情）、动作。

两种动作：

- **跳转** —— 打开一个地址，支持用 `{字段}` 插值
- **调数据接口** —— 调一条已登记的数据接口

还可以配**可见条件**（按当前行的数据求值）与**权限标识**。

**⚠️ 工具栏按钮不判可见条件** —— 工具栏没有「当前记录」可以求值。

**⚠️ 可见条件只是界面级的。** 它决定按钮显不显示，不是权限。真正的权限在服务端。

## 详情页页签

详情弹窗里除了表单本身，还能挂几个页签：

- **变更记录** —— 时间线形式展示改动历史。要数据绑定里开了变更日志
- **关联数据** —— 列出别的表单里挂在这条记录下的数据

配的是一份清单（而不是几个布尔开关），所以顺序和文案都可以改。

## 变更记录

开了变更日志后，每次更新记一条「谁、什么时候、把哪个字段从什么改成了什么」。

只记**真的变了**的字段。判定「什么算变了」时做了归一化：
`null` 与空串不算变、数字 `1` 与字符串 `"1"` 不算变 —— 否则日志里会全是噪音。

## 打印模板

用富文本编辑器写模板，占位符是 `{字段}`。

- 点字段清单可以把占位符插进正文
- 值进模板前会做 **HTML 转义** —— 值里的 `<script>` 会变成文本而不是被执行
- 模板本身落库前会被清洗一遍
- 发布校验会拦「占位符引用了取不到值的字段」

配了模板之后，列表行与详情上才会出现「打印」按钮；勾了「批量打印」的话，
选中多条会拼成一份文档，中间用分页符隔开。

### 子表明细：把 `{#子表字段}` 放进要重复的那一行

标记放在明细行的任意一个单元格里，这一整行就按明细条数重复，行内的 `{列}`
取当前明细行的值。标记本身不印出来。

```html
<table>
  <thead><tr><th>费用项目</th><th>数量</th><th>金额</th></tr></thead>
  <tbody>
    <tr><td>{#costs}{cost_item}</td><td>{cost_qty}</td><td>{cost_amount}</td></tr>
  </tbody>
</table>
```

- **用设计器右侧的「插入明细表格」按钮生成**，它一次给出结构正确的表格
- 子表没有数据时**整行去掉**，而不是留一行空格子
- 行内的值同样做 HTML 转义
- 发布校验拦三件：**标记没放在表格的一行里**、**引用的子表不存在**、
  **行内的列不是该子表的字段**。三件都属于「不拦就静默出错」

#### ⚠️ 为什么不是成对的 `{#子表}…{/子表}`

一开始就是成对的，标记写在 `</tr>` 与 `<tr>` 之间。它在字符串层面完全正常、
打印也印得对 —— 但只要在设计器里打开一次模板再存回去就废了：

HTML 的 **foster parenting** 规则规定，`<table>` 里不在单元格内的文本节点要被
整段挪到表格**前面**。富文本编辑器读进来再吐出去之后，两个标记挨在一起跑到了
表格外，中间什么都不剩，明细行落在了循环之外。现象是「模板没动过，打开保存一下，
明细就印不出来了」，没有任何报错。

标记放进单元格里则不受这条规则影响。单标记还顺带消灭了「前后对不上」与
「少写一半」这两类错误。

**刻意没做的一件**：条码 / 二维码。它需要在 `{字段}` 之外再加一套形如 `{barcode:字段}`
的语法，而「用户在两种写法之间猜」正是这个模块一直在避免的。

## 列表打印

与上面的**单据打印**是两件事：

| | 单据打印 | 列表打印 |
|---|---|---|
| 印什么 | 一条记录一页，按模板排版 | 屏幕上这张表原样印出来 |
| 依赖 | 必须配打印模板 | 不需要模板 |
| 按钮 | 行内「打印」/ 工具栏「批量打印」 | 工具栏「打印列表」 |

列表打印是**所见即所得**的：分组表头印成两行表头、合并单元格带 `rowspan`、
分组行印成整行一格、合计行印进 `tfoot`。这几样恰恰是用户要打印这张表的原因 ——
按扁平列清单印一遍的话，得到的是「这批数据」而不是「这张报表」。

印的是**当前看到的这一页**：刚筛完、刚排完序、刚折叠了两个分组，印出来就是那个样子。
页脚会写明印了多少条、共多少条。要全量请用「导出」。

## 导出

工具栏勾「导出」即可。导出的是**当前查询条件下**的数据，不是全表。
脱敏字段导出的也是掩码值。

## 这些配法会静默失效

| 配法 | 表现 |
|---|---|
| 配了变更记录页签但没开变更日志 | 页签点开永远是空的（设计器会提示） |
| 配了打印按钮但没配模板 | 按钮不会出现（设计器会提示） |
| 给自定义按钮挂权限标识但没建对应权限 | 按钮对所有人隐藏 |
| 指望「可见条件」当权限用 | 它只是界面级的，改请求照样能调 |
| 打印模板里写了含花括号的其它内容 | 会被当成占位符解析 |
| `{#items}` 放在了表格外面（或表格与标记之间隔着别的内容） | 那一行不会重复，明细印不出来，发布会被拦 |
| 以为「打印列表」需要先配打印模板 | 两者不相干，列表打印不看模板 |
