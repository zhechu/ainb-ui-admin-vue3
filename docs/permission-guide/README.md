# 权限体系使用手册

给系统管理人员看的。目标是：**看完能独立把一个人的权限配对，并且知道哪些配法会静默失效。**

这套权限体系覆盖菜单/按钮、表单数据的行与字段、以及流程的发起与查看。它的判定全部基于
`sys_grant` 一张授权表，不再看旧的「角色-菜单」关联。

## 一页纸速览

```
        谁                    对什么               能做什么         结果
   ┌──────────┐        ┌──────────────┐      ┌──────────┐    ┌────────┐
   │ 角色 ROLE │        │ 菜单/按钮     │      │ VIEW 查看 │    │ ALLOW  │
   │ 用户 USER │   ×    │ 数据集(表单)  │  ×   │ CREATE   │ →  │ DENY   │
   │ 部门 DEPT │        │ 列 / 字段     │      │ START 发起│    └────────┘
   │ 岗位 POST │        │ 流程 / 分类   │      │ MANAGE   │        ↑
   │ 用户组    │        └──────────────┘      └──────────┘   还可叠加：
   │ 所有人 ALL│                                             · 行过滤规则
   └──────────┘                                             · 字段显示模式
                                                            · 有效期
```

**三条铁律**，记住这三条能避开绝大多数问题：

1. **DENY 永远赢。** 同一个人身上只要有一条生效的 DENY，其它所有 ALLOW 都不算。
2. **没配过 = 看资源的默认效果。** 不是「没配就放行」，也不是「没配就拒绝」——
   菜单/按钮默认拒绝，数据集的列和字段默认放行。详见 [02](02-核心概念.md)。
3. **授权会沿资源树往下继承。** 给一个分类授权，它下面的流程都继承；
   给数据集授权，它的列和字段都继承。

## 五个入口在哪

| 要做的事 | 在哪 |
|---|---|
| 给角色配权限（最常用） | 【系统管理 → 角色管理】→ 某行的「资源授权」按钮 |
| 管行过滤规则 | 【系统管理 → 规则管理】 |
| 查「他为什么没权限」 | 【系统管理 → 权限诊断】 |
| 配某个资源的字段权限/槽位/分享策略 | 从上面任一入口打开「资源配置」面板 |
| 配流程权限 | 【工作流程 → 流程模型】→ 进某个流程的定义列表 → 「权限配置」 |

## 配之前必须知道的一件事

**超级管理员看不出问题。** 后端对超管直接放行，不走授权判定。所以：

- 用超管账号测权限，永远是「都能用」，测不出任何配置错误
- **必须用一个普通账号验证**
- 例外：【权限诊断】页故意不对超管短路，所以它显示的是「授权引擎真实的判定路径」，
  可能显示超管「无权限」——那是正常的，不代表超管用不了
